# ANUJ — Graphic Designer Portfolio

## Free publishing with GitHub Pages

1. Create a free account at GitHub.
2. Create a new **public repository** named `anuj-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/root`, then Save.
7. GitHub will give you a free address like:
   `https://YOUR-USERNAME.github.io/anuj-portfolio/`

## Before publishing

Open `index.html` and replace:
- `your@email.com`
- `919999999999`
- Portfolio placeholder projects
- Experience text if needed

For real project images, replace each `.project-img` placeholder with your image or add an `<img>` element.

The site is responsive and designed for a modern graphic-design portfolio.
